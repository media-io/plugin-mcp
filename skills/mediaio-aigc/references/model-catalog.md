Use the model-specific request.inputs and request.options in the tool schema. Never copy options between models or infer an upstream code from a display name. Prices and entitlements come from the server; this catalog promises neither free access nor fixed charges.

Where the workflow and Web UI disagree, the release uses verified intersections. Automatic dimensions, arbitrary storyboard/character payloads, URL fetching and UI concurrency are not exposed. Some non-UI settings remain fixed to declared upstream defaults; model coverage does not mean every Web control is supported.
